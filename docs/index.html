Workflow

One App for the Complete Pain Drawing Pipeline

SeePainX is organized around three persistent project folders and four main pages. The left window shows Template, Input, and Output folders. The center window changes according to the selected page. The right window shows run progress and important process messages.

  • Template: stores body templates and masks used by normalization and drawing workflows.
  • Input: stores raw scans, PDFs, images, SVGs, and drawings that should be viewed or processed.
  • Output: stores normalized images, pain acquisition files, questionnaire spreadsheets, pain profiles, and classification reports.

Pages

Main SeePainX Pages and Features

Each page focuses on one part of the research workflow while keeping the same project folders, tabs, and run controls available.

N

Normalize

The Normalize page converts raw scans, PDFs, or image files into standardized normalized images using a selected template. It is designed for batch processing and visual review.

  • Select a template file from the Template folder.
  • Load raw input images or PDFs from the Input folder.
  • Run normalization for one or many files.
  • Save generated images to the Output folder.
  • Reload output automatically while processing.
  • Display normalized files in tabs.
  • Show alignment score and mean error when available.
  • Open PDFs as fitted page previews.
  • Zoom, pan, and fit loaded images.
  • Use built-in demo images before loading real data.
P

PainAcquisition

The PainAcquisition page is used to collect and edit digital pain drawings directly on a template. It supports drawing, erasing, intensity colors, zooming, panning, and structured saving.

  • Draw pain areas using the pencil tool.
  • Select pain intensity colors from yellow to black, moving from low to high intensity.
  • Use predefined pencil and eraser thickness options.
  • Remove marks using the eraser tool.
  • Pan and zoom the drawing canvas.
  • Open multiple drawing tabs.
  • Load and edit previously saved drawings.
  • Save drawing data as JSON, PNG, and SVG.
  • Use bundled templates and masks.
  • Use drawing guidance overlays while starting a new drawing.
Q

Questionnaire

The Questionnaire page creates structured forms for patient or study data. Responses are saved into a spreadsheet-oriented format so the data can be reviewed and analyzed later.

  • Add text question blocks and answer fields.
  • Add checklist and bullet-style question sections.
  • Add tables with structured rows, columns, and checkbox entries.
  • Add image blocks and pain drawing references.
  • Edit questionnaire blocks directly in the page.
  • Save all questionnaire content into a single Excel workbook.
  • Store each question as a spreadsheet header.
  • Store table values structurally.
  • Store checkbox states correctly.
  • Use multiple questionnaire tabs when needed.
PP

Pain Profiles

The Pain Profiles tool on the Analyze page generates class-level pain profile images from organized pain drawing data. Generated profiles are saved to the selected output folder and displayed in tabs.

  • Use selected Template, Input, and Output folders.
  • Generate pain profiles from class-organized input data.
  • Load generated profiles into tabs as soon as they are created.
  • Inspect pain profiles visually inside the app.
  • Use demo profiles to understand the expected output.
  • Clear or delete analysis tabs when needed.
  • Use the right window to review run progress.
  • Keep generated outputs in the selected Output folder.
C

Classification

The Classification tool on the Analyze page compares a loaded pain drawing against selected pain profile classes. It supports single-image classification and batch classification of the full Input folder.

  • Click an input image or PDF to load it into a classification tab.
  • Select the classes that should be considered by the model.
  • Optionally enable normalization before classification.
  • Select a template when normalization is required.
  • Press Run to classify the active image.
  • Run batch classification when no single image is selected.
  • Save classification results as an Excel file in Output.
  • Show selected class profiles in the output block.
  • Highlight the predicted class after classification.
  • Open PDFs as fitted full-tab previews.

Classification Flow

Single Run and Batch Run

Single run: click an input image from the left window, normalize if needed, select the classes and template if normalization is selected, then press Run.

Batch run: leave the image area empty, decide whether normalization is required, select the classes and template if needed, then press Run to process the input folder and save the Excel result to Output.

Good Practice

Recommended Use

Keep Folders Organized

Use separate folders for raw inputs, normalized outputs, questionnaire files, and analysis results. This keeps the file tree readable and reduces accidental overwriting.

Check Important Outputs

After normalization or classification, inspect sample files and review the generated spreadsheet before using the results for research analysis.

Protect Study Data

Use anonymized identifiers where possible and avoid storing unnecessary personal information in filenames or folder names.
