Research software for structured pain drawing workflows

SeePainX

PD AcquisitionQuestionnaire Data CollectionNormalizationAnalysis

SeePainX provides a unified desktop workflow for acquiring digital pain drawings, collecting structured questionnaire responses, normalizing scanned pain drawings to a common anatomical reference, and generating cohort-level pain profiles. The application separates patient-facing data entry from clinician-facing configuration and processing while keeping templates, input data, and outputs organized in a consistent file structure.

Research use only

SeePainX is not a certified medical device and must not be used as the sole basis for diagnosis, treatment, or clinical decision-making.

Access modes

Purpose-specific interfaces

SeePainX limits visible tools according to the active role so participants can focus on data entry while clinicians retain control over templates and processing.

Patient mode

Focused data entry

  • Provides access to PD Acquisition and Questionnaire only.
  • Shows approved anatomical and questionnaire templates.
  • Allows drawing, answering, clearing, and saving participant data.
  • Prevents modification of questionnaire questions and template structure.
  • Keeps normalization, analysis, and unrelated study data unavailable.
Clinician mode

Configuration and analysis

  • Provides access to all four workflow pages.
  • Creates and edits questionnaire templates.
  • Configures workflow parameters and output formats.
  • Runs normalization and pain-profile generation.
  • Reviews outputs, quality measures, logs, and organized result files.

Application guide

Four connected workflows

Each page follows the same tabbed workspace, file-tree, parameter, and output conventions, while exposing tools specific to its task.

01

Patient and clinician

PD Acquisition

Collect pain markings directly on a standardized anatomical template using a mouse, touch input, or supported digital pen.

Template and canvas

  • Opens the configured front-and-back anatomical template by default.
  • Loads bundled PD templates or templates selected from the PD Template folder.
  • Uses the matching anatomical mask to restrict drawing to valid body regions.
  • Supports multiple draggable tabs, fit-to-window viewing, zooming, and panning.

Drawing tools

  • Brush: records pain regions with selectable intensity colors and adjustable size.
  • Opacity: changes brush opacity using fixed stepped values.
  • Eraser: removes complete strokes or selected stroke areas, according to settings.
  • Move and fit: reposition or refit the anatomical page without changing the drawing.
  • Clear: removes all markings from the active tab after confirmation.

Saving

Use Save to write the active pain drawing to the selected Output folder. Files are named from the participant ID, template code, date, and time. If the same filename already exists, SeePainX asks whether to replace it or save a newly named copy. Saving is blocked until an Output folder is selected.

02

Structured study data

Questionnaire Data Collection

Create reusable questionnaire templates in Clinician mode and collect protected participant responses in Patient mode.

Template authoring

  • Text: adds a question with a free-text answer field.
  • Checklist: creates multiple Boolean options; Enter adds an option and Shift+Enter inserts a line break.
  • Table: adds structured rows and columns, with controls for adding, removing, and inserting checkbox cells.
  • Image: adds a clinician-selected reference image for a visual question.
  • Formatting: provides bold, italic, underline, alignment, list, undo, and redo controls.
  • Locking: protects questions and structure while leaving answer fields editable for participants.

Participant workflow

  • Load an approved questionnaire from the Quest Template folder.
  • Complete text fields, checklist options, and editable table cells.
  • Use the clear-answer control to prepare the same template for the next participant.
  • Question text, table structure, and reference images remain protected in Patient mode.
  • Completion progress reflects the number of answered questionnaire subwindows.

Saving

Clinicians save questionnaire templates as JSON files in the selected Output folder. Patient responses are appended to one template-specific Excel workbook: each participant occupies a structured record, questions define the columns, checklist values are stored as True or False, tables retain their row-and-column arrangement, and the save date and time are recorded.

03

Clinician mode

Normalization

Register scanned pain drawings to a common anatomical template so corresponding anatomy occupies consistent pixel coordinates.

Inputs and registration

  • Select PD Template, Input, and Output folders from the file manager.
  • Select the required template by clicking it in the PD Template tree.
  • Convert PDF, SVG, and raster inputs to the configured grayscale resolution.
  • Use enabled ORB, SIFT, and LSD feature combinations to form registration candidates.
  • Evaluate enabled global and local homographies and select the highest normalization score.
  • Trigger larger descriptors when the configured score criterion requires reevaluation.

Processing and quality control

  • Use template-guided nearest-neighbor distances to calculate accuracy and mean pixel error.
  • Remove thin anatomical outlines with optional morphological processing.
  • Apply the template mask to suppress marks outside the anatomical region.
  • Overlay retained pain regions onto the clean template when template overlay is enabled.
  • Run/Pause: starts or pauses the active batch; Stop terminates all workers.
  • The run panel reports device use, paths, progress, filename, accuracy, and mean error.

Saving

Normalized files are written to the selected Output folder in the enabled global formats. A single organized Excel report records each image, selected feature method, descriptor scale, homography values, quality metrics, parameters, and final path. Optional distance arrays and analysis artifacts are created only when enabled.

04

Clinician mode

Analysis

Aggregate organized pain drawings by class to generate interpretable spatial pain-frequency profiles.

Pain-profile generation

  • Groups input files according to their class or subfolder.
  • Converts inputs and the selected template to grayscale, resizes them, and applies binary thresholding.
  • Removes the anatomical outline using morphology or template subtraction.
  • Optionally preserves low, medium, and high drawing intensities as separate profiles.
  • Accumulates valid pixels across participants and applies the anatomical mask.
  • Applies minimum-overlap, clipping, or quantile settings before heatmap rendering.

Visualization and controls

  • Creates a single-intensity profile by default or four intensity profiles when enabled.
  • Maps nonzero occurrence frequencies from the selected low-frequency color to dark red.
  • Displays one adaptive frequency bar for the currently selected pain-profile tab.
  • Can save relative-frequency, cumulative-frequency, and quantile histograms.
  • Loads newly generated profiles into available tabs during processing.
  • Run/Pause and Stop provide the same controlled batch behavior as Normalization.

Saving

Each class-level pain profile is saved under a pain_profile directory in the selected Output folder and only in globally enabled formats. When analysis-step export is enabled, representative preprocessing images, accumulated maps, masks, frequency bars, and statistical plots are stored separately for inspection.

Data practice

Study data organization

Separate source and result data

Keep templates, raw inputs, questionnaire templates, participant results, normalized files, and analysis outputs in clearly separated directories.

Use anonymous identifiers

Avoid participant names and unnecessary personal information in filenames. Prefer study-specific pseudonymous IDs.

Inspect generated outputs

Review representative normalized drawings, alignment metrics, questionnaire columns, and pain profiles before downstream analysis.
